What it does

Intelligent email management, with privacy in mind.

Inbox Zero is a capable email assistant. The deployment documentation describes a narrower set of behaviours than the software allows, but the live restrictions still require confirmation.

Connects to Gmail

Google OAuth links the operator’s Gmail accounts to the self-hosted app. The app reads mail and metadata through the Gmail API to build its local view. The exact scopes are pending confirmation.

AI-assisted organisation

Language models help classify messages and suggest labels or rules. Rules run against the local copy and apply labels through the Gmail API. Provider configuration and data practices require confirmation.

Private access (pending)

The deployment documentation describes local-only access through an SSH tunnel. The bind address, tunnel configuration and absence of a public endpoint still need verification.

Guardrails

Capable software, conservative settings.

The underlying application can send, delete and automate far more than this deployment is documented as allowing. The restrictions below must be confirmed against the live environment before they are presented as facts.

Email remains valuable and hard to replace. The deployment is described as favouring reviewable actions over autonomous ones.

Google data

Scopes, in plain language.

These are the Google OAuth scopes configured for this deployment. The privacy policy explains how each is used, stored and shared.

Configured Google OAuth scopes for the Inbox Zero deployment.
Scope What it allows How it is used here
userinfo.profile
userinfo.email		 Basic profile information: name, primary email address and profile picture. Creates the local account, displays the signed-in Google account and associates mail with the correct user.
gmail.modify Read email messages and metadata, and manage labels, drafts and message state. Reads and classifies mail, applies labels and runs rules. Sending and deletion are documented as disabled; confirm the live configuration.
gmail.settings.basic Read and manage basic Gmail settings, including filters. Supports rule and filter management features in the app.
Note

The Google People API is documented as enabled so the sign-in flow can retrieve the account’s primary email, name and photo. It is described as account linking, not contact discovery. Confirm this in the Cloud project.

Data path

Where the mail goes.

A simplified path from Google to the local deployment. The draft privacy policy is the reference, but its claims are not yet verified.

  1. 01

    Authorisation

    The operator signs in with Google and grants the scopes above. The documentation states that OAuth tokens are stored by the self-hosted application using a deployment-specific encryption secret; verify the mechanism.

  2. 02

    Local storage

    Message content, metadata, labels, rules and account settings are documented as stored in a dedicated PostgreSQL database on the private host. Redis is described as supporting queues and short-lived state. Confirm the live setup.

  3. 03

    AI-assisted analysis

    Selected email content is documented as sent to Anthropic’s API for classification and organisation. Groq is named as a possible fallback. Sensitive-data redaction is described as applied first. Confirm the active providers and redaction enforcement.

  4. 04

    Labels and rules

    The app is documented as writing labels and rule outcomes back to Gmail through the Gmail API. Sending and deletion are described as disabled. Confirm both statements against the live deployment.

  5. 05

    Local access

    The deployment documentation describes access through an SSH tunnel rather than a public interface. The tunnel, bind address and exposure still need confirmation. This website has no connection to the inbox.

Access & privacy

An independent, private deployment.

Inbox Zero is open-source software. This is an independent, self-hosted deployment and is not operated by the upstream maintainers. The deployment documentation describes a private access model; confirm the access path and whether any endpoint is reachable. The upstream project is at github.com/elie222/inbox-zero.

Google API Services User Data Policy: Inbox Zero’s use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. This is a draft commitment; compliance has not been independently verified.
