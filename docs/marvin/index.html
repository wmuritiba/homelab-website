Marvin

What it does

A familiar interface, a narrow backend.

Marvin lives in WhatsApp. Behind that simple interface, the work is deliberately split into small, auditable steps.

Answers in WhatsApp

Family members send a message as they normally would. Marvin replies in the same conversation, using a private WhatsApp bridge rather than a public web app.

Consults calendar events

When a question is about the schedule, Marvin can read the connected Google Calendars and turn the result into a short answer. The production workflow currently queries events. Creating, changing and cancelling events through natural-language WhatsApp commands is planned for a future stage.

Handles text and voice

Voice notes are transcribed so they can be treated like typed messages. The documentation states that the transcription service handles audio in memory; this requires confirmation.

Google data

Google Calendar access, current and planned.

Marvin currently uses Google Calendar to help answer scheduling questions. The production workflow only queries events. The standard OAuth credential requests broader calendar permissions, including write access. Creating, changing and cancelling events through WhatsApp is planned and will require appropriate authorisation. The exact granted scopes must be confirmed.

The privacy policy is a draft. It describes the intended data, purpose, storage, processors and deletion route; each item must be verified before publication.

Request flow

From message to reply.

A high-level view of the path a message takes. The production system uses a self-hosted WhatsApp bridge and an automation workflow.

  1. 01

    Message received

    A family member sends a text message or voice note to the private WhatsApp number. The WhatsApp bridge passes it to the self-hosted automation layer.

  2. 02

    Intent and context

    The workflow classifies the request. Schedule questions take a deterministic calendar path; general questions go to the language model with the conversation context.

  3. 03

    Scoped lookup

    For calendar questions, the workflow currently queries the connected calendars for the information needed to answer. Creating, changing or cancelling events is planned for a future stage and is not implemented.

  4. 04

    AI processing

    Anthropic’s Claude models are documented as generating the reply, and Groq as transcribing voice notes. A local Ollama fallback is mentioned in the project documentation but is not assumed here. Confirm the active provider configuration.

  5. 05

    Reply and history

    The reply is sent back through WhatsApp. The project documentation describes conversation history stored in a self-hosted SQLite database; this and its retention need confirmation.

Processors

External AI, named clearly.

Marvin is self-hosted, but it is not self-contained. Message text and, for voice notes, transcribed text are sent to external providers to generate a response.

The privacy policy identifies each provider and links to its own privacy documentation. The claims that Google user data is not sold, used for advertising or used to train models by this deployment are intended commitments that still require verification.

Anthropic

Claude models interpret the request and compose the reply. Anthropic’s data handling, retention and model-training practices require separate confirmation.

Groq

Speech-to-text for voice notes is documented for Groq. Groq’s retention and training practices, and whether it is the active provider, require confirmation.

Provider terms

Data retention and model-training practices must be checked separately for each provider. A local fallback is mentioned in the documentation but is not assumed.

Access & privacy

Private by default.

Marvin is not published from this site. The deployment documentation describes access as limited to the operator and configured family members; the access model and whether any application endpoint is reachable still need confirmation.

Google API Services User Data Policy: Marvin’s use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. This is a draft commitment; compliance has not been independently verified.
